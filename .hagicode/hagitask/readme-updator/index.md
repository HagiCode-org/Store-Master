# README requirements

## Audience and focus

- Address people who use the Store Master desktop app (Electron, React, TypeScript) for store management, and developers who build it.

## Required content

- Keep features, tech stack, development, project structure and license.
- State only features that `src/` shows. The license badge and `LICENSE` say MIT while `package.json` says AGPL-3.0; the README must follow `LICENSE` until that mismatch is resolved.

## Exclusions

- Exclude store credentials, signing material, tokens, internal hosts, machine-specific paths and private links.
